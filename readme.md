VANTA-Amazon Rainforest Website:-
Vanta is a simple and clean website about the Amazon Rainforest. It shares key facts about rainforest wildlife, plants, and amazing things which are present there in a cool way.
DEMO Link for the website:-
Click here-[https://evvacarter.github.io/VANTA/]

What's Included---
1) Overview: Key facts about the size, oxygen, and wildlife, plants and many more things.
2) Categories: Easy-to-read sections for discover and cool interesting facts.
3) Mobile Friendly: Works smoothly on both phone and computers.

Built With---
* HTML5 - HTML5 is used for all it's structure, layout and content.
* CSS3 - For adding colors, fonts, layout styling and for good animation and hover effects to inhance it's look.
* Java Sript- also played an important role as it is used for adding navbar's icon for mobile screen.

How to Run Locally--
1. Download or clone this project:
git clone https://github.com/evvacarter/VANTA.git

2. Go into the project folder:
cd VANTA

3. Open index.html in your web browser

Project Files--
index.html- The main web page code.
style.css- All page styles and formatting .
script.js- toggle button for the mobile navbar.
readme.md- Project description file.
